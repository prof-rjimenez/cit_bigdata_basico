# cit-intro-bigdata
Materiales y proyectos del curso-taller “Introducción a Big Data” (CIT-UNA/KOICA). Aprenderás fundamentos de Big Data, optimización SQL y diseño de pipelines ETL/ELT con PostgreSQL, Airflow y Python, usando datos abiertos del Paraguay para construir modelos analíticos y reportes en Power BI.
